# PengchuanTray · 贴传 Windows 助手

一个开源的 Windows 托盘小工具，配合贴传 手机 App 做局域网文件传输。

- [项目介绍（2026-10-24）](blog/2026-10-24-introducing-pengchuantray.md)
- [GitHub 仓库](https://github.com/carlhtzuo666/pengchuan-tray)
- [下载最新版](https://github.com/carlhtzuo666/pengchuan-tray/releases/latest)
- [反馈问题](https://github.com/carlhtzuo666/pengchuan-tray/issues)

## 快速开始

1. 手机贴一下 NFC 标签，进入「等待电脑接入」；
2. 电脑运行 `PengchuanTray.exe`（或 `dotnet PengchuanTray.dll`）；
3. 托盘出现后，文件会自动保存到 `桌面\贴传`。
