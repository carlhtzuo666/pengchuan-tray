## 三、文案草稿（可直接粘贴到商店后台）

### 应用名称

```
贴传助手
```

### 简短描述（≤ 200 字符）

```
手机碰一下 NFC 标签，电脑自动接收文件。手机与电脑同一 Wi-Fi 下局域网直传，文件不经过任何服务器；也能把手机上的文字、图片直接送进电脑的聊天框或邮件正文。
```

### 详细描述

```
贴传助手让「手机 → 电脑」传东西变成一步操作。

【核心能力】
· 碰一碰直传：手机贴近电脑上的 NFC 标签，选文件即传，电脑自动保存到下载文件夹
· 局域网直连：手机与电脑在同一 Wi-Fi（或手机热点）下直接传输，文件不经过任何服务器，速度快、隐私好
· 文字即时送达：手机上打字，电脑当前光标所在的输入框直接出现；也能一键把文字复制到剪贴板
· 图片/视频/文件直接进对话框：手机上选好图片或文件，电脑的 AI 对话框、邮件正文里直接出现该文件，省去「先传文件再手动插入」
· 远程回车：手机上的 Enter 按钮等同于在电脑上按回车，可以把已经输入好的内容直接发出去
· 传输记录：最近传过什么，在手机 App「我的」里随时回看

【适合谁】
· 经常要把手机照片、文件发到电脑上继续处理的人
· 用 AI 对话工具办公，需要频繁把手机里的图贴进对话框的人
· 电脑不支持蓝牙文件传输、或用不惯微信文件助手的人

【隐私】
· 局域网传输的文件不经过任何服务器
· 只有你主动开启云取件（会员功能）时，文件才会上传到云端临时保存 24 小时
· 不收集位置、通讯录等与传输无关的数据

电脑端需与手机端「贴传」App 配合使用。
```

### 系统要求说明

```
Windows 10 版本 2004（内部版本 19041）或更高版本，64 位。
需要与手机端「贴传」App 配合使用（手机需支持 NFC 或扫码）。
```

### 隐私政策 URL

```
<你发布 PRIVACY.md 后的 HTTPS 链接，例如 https://share.ailinkfree.com/privacy>
```

### 提交时「此应用是否访问个人信息」答复要点

- 收集哪些：仅传输所需的文件与文字内容、账号邮箱（云取件功能才需要）
- 用途：仅用于在用户自己的设备间传输，不用于广告、画像、第三方共享
- 存储：局域网传输不落任何服务器；云取件临时保存 24 小时
- 用户控制：可随时关闭云取件、清空传输记录、注销账号

## 五、提交后可能被问到的问题（提前准备答案）

| 问题 | 建议答复 |
|---|---|
为什么需要 `runFullTrust` 能力？ | 这是 Windows 桌面托盘应用的标准打包方式（`Windows.FullTrustApplication`），应用本身是 Win32 程序，需要访问文件系统、系统托盘与局域网套接字才能完成文件传输 |
为什么需要防火墙规则？ | 应用在局域网内监听一个本地端口（默认 8080），供同一网络下的手机直接连接取件；不开放则无法完成「局域网直传」 |
是否收集用户数据？ | 局域网传输的内容完全不经过服务器；仅「云取件」会员功能会把文件临时上传 24 小时，且由用户主动开启 |
为什么没有代码签名？ | 当前通过商店分发由微软重签；独立发布的安装包正在申请开源项目免费签名（SignPath Foundation） |
